Fixes for Expand's widescreen in split screen and the pause menu. Like v0.1.12 it contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.13-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.13-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- With Expand, two players' split screen is widened to the window's sides like one player's view, its radars included, instead of drawing black past hard edges.
- With Expand, the window beside three or four players' quarters and the Combat Simulator's menus is black, instead of an old frame stretched to its sides.
- With Expand, the pause menu's and the end screen's blurred picture of the level reaches the window's sides.

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
