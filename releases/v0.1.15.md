A fix for the memory a long session kept adding, and a crash that now says where it happened. Like v0.1.14 it contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.15-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.15-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- The game no longer adds to its memory and video memory with every mission played (up to about 120 MB of each per mission, never given back): over a long session, half an hour or more, both kept growing.
- A crash now writes where it happened at the end of the log: the error, the address it faulted on, and on Windows the program's stack. Those lines in a crash report say which part of the game crashed.
- When the graphics device is lost (a driver reset, a GPU hang), the game starts again on a new one instead of crashing or freezing, and closes with a message saying why if it is lost again within a minute.

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
