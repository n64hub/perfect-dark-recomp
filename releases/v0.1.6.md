Smoother motion and a fix for starting on Windows with little memory free, from the shared renderer and runtime. Like v0.1.5 it contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.6-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.6-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Smoother scrolling textures:** textures the game scrolls slowly, such as water and skies, move smoothly on every frame drawn instead of in steps.
- **Smoother moving shapes:** shapes the game moves by changing their points itself, rather than through a matrix of their own, glide between the game's frames instead of moving only on them.
- **A rare glitch gone:** for a single frame, a small object far away could be drawn huge in front of everything. It no longer is.
- **Starts on Windows with little memory to spare:** the game now asks Windows only for the 512 MB of console memory it uses, so it no longer fails to start with "Failed to allocate memory!" on a PC with little free memory.

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
