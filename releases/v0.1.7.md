A fix for quitting on Linux, from the shared frontend. Like v0.1.6 it contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.7-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.7-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Quits at once on Linux when asked to:** logging out, a session timeout or Ctrl+C in the terminal that started it now quits the game at once. Before, it opened a quit prompt nobody could answer, and the game only ended when it was killed. Closing the window still asks first.

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
