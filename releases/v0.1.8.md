Controls for a modern pad, as the decompilation's PC port has them. Like v0.1.7 it contains no game data: you need your own ROM of the USA release's second revision (*Perfect Dark (U) (V1.1)*, a big-endian `.z64` of 32 MiB, MD5 `e03b088b6ac9e0080440efed07c1e40f`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PerfectDarkRecompiled-v0.1.8-windows-x64.zip` and run `PerfectDarkRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PerfectDarkRecompiled-v0.1.8-linux-x64.tar.gz` and run `PerfectDarkRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Ext, controls for a modern pad:** a new control style, as the decompilation's PC port plays a pad: the right stick looks and turns, the left stick walks and strafes, RT fires and LT aims, X reloads, Y and B change to the next and previous weapon, LB opens the weapon menu and a click of the left stick crouches. New agent files and new Combat Simulator players start on it; for a file you already have, pick Ext in Control Style, or 1.1 for the controls as the game shipped.

The [README](https://github.com/n64hub/perfect-dark-recomp#readme) has every setting and what is still wrong; [docs/building.md](https://github.com/n64hub/perfect-dark-recomp/blob/main/docs/building.md) says how to build it yourself.
